## Problem Descriptions

### 16. 3Sum Closest
**Difficulty:** Medium

Given an integer array `nums` and an integer `target`, find three integers in the array whose sum is closest to the target.

**Concepts Used**
- Sorting
- Two Pointers
- Greedy Comparison

---

### 34. Find First and Last Position of Element in Sorted Array
**Difficulty:** Medium

Given a sorted array, find the starting and ending position of a target value in **O(log n)** time.

**Concepts Used**
- Binary Search
- Lower Bound
- Upper Bound

---

### 66. Plus One
**Difficulty:** Easy

Given a large integer represented as an array of digits, increment the integer by one.

**Concepts Used**
- Array Traversal
- Carry Handling
